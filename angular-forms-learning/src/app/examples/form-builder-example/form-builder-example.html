FormBuilder の基本

FormBuilderは、より簡潔な構文でフォームを作成できる便利なサービスです。

基本的なFormBuilder

名前 メールアドレス 年齢

フォームの値:

{{ getProfileValue() | json }}

バリデーション付きフォーム

ユーザー名 @if (registrationForm.get('username')?.hasError('required') && registrationForm.get('username')?.touched) { ユーザー名は必須です } @if (registrationForm.get('username')?.hasError('minlength')) { 最低3文字必要です } メールアドレス @if (registrationForm.get('email')?.hasError('required') && registrationForm.get('email')?.touched) { メールアドレスは必須です } @if (registrationForm.get('email')?.hasError('email')) { 有効なメールアドレスを入力してください } パスワード @if (registrationForm.get('password')?.hasError('required') && registrationForm.get('password')?.touched) { パスワードは必須です } @if (registrationForm.get('password')?.hasError('minlength')) { 最低8文字必要です } 利用規約に同意する

コード例:

// TypeScript
constructor(private fb: FormBuilder) {}

profileForm = this.fb.group({
  name: [''],
  email: ['', [Validators.required, Validators.email]],
});

// HTML
<form [formGroup]="profileForm">
  <input matInput formControlName="name">
</form>
