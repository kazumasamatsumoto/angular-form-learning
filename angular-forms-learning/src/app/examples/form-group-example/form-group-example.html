FormGroup の基本

FormGroupは複数のFormControlをグループ化して管理するクラスです。

基本的なFormGroup

名 姓 メールアドレス 電話番号

フォームの値:

{{ getUserFormValue() | json }}

ネストされたFormGroup

個人情報

名前 年齢

住所

郵便番号 都道府県 市区町村

フォームの値:

{{ getAddressFormValue() | json }}

コード例:

// TypeScript
userForm = new FormGroup({
  firstName: new FormControl(''),
  lastName: new FormControl(''),
});

// HTML
<form [formGroup]="userForm">
  <input matInput formControlName="firstName">
</form>
