FormControl の基本

FormControlは単一のフォームコントロール（input、select等）を管理するクラスです。

基本的な使い方

名前

入力値: {{ getName() }}

メールアドレス

入力値: {{ getEmail() }}

年齢

入力値: {{ getAge() }}

コード例:

// TypeScript
nameControl = new FormControl('');
emailControl = new FormControl('example@example.com');

// HTML
<input matInput [formControl]="nameControl">
