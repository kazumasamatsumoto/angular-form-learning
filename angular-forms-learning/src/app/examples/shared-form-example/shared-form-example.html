複数コンポーネントでのフォーム値共有

サービスを使用して、複数のコンポーネント間でフォームの値を共有する例です。

InputとSliderが連動して動作します。

数値入力

値を入力 (0-100)

現在の値: {{ valueControl.value }}

スライダー

現在の値: {{ valueControl.value }}

パーセンテージ表示

{{ valueControl.value }}%

実装のポイント:

// サービス (shared-form.service.ts)
private valueSubject = new BehaviorSubject<number>(50);
value$ = this.valueSubject.asObservable();

setValue(value: number): void {
  this.valueSubject.next(value);
}

// コンポーネント
constructor(private sharedForm: SharedForm) {}

ngOnInit(): void {
  // サービスの値を購読
  this.sharedForm.value$.subscribe(value => {
    this.valueControl.setValue(value, { emitEvent: false });
  });

  // FormControlの変更をサービスに通知
  this.valueControl.valueChanges.subscribe(value => {
    this.sharedForm.setValue(value);
  });
}

仕組みの説明:

  • BehaviorSubject: 現在の値を保持し、新しい購読者に即座に最新の値を送信
  • Observable: 値の変更を複数のコンポーネントに通知
  • valueChanges: FormControlの値の変更を検知
  • emitEvent: false: 無限ループを防ぐために、値を設定するときにイベントを発行しない
