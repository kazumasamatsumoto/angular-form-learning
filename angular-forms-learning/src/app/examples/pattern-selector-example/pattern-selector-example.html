パターン選択とパラメータ調整

3つのパターンが常に表示されており、それぞれ独立して4つのパラメータ（A, B, C, D）を横並びで調整できます。ラジオボタンで使用するパターンを選択してください。

実装のポイント:

// TypeScript
patterns: PatternData[] = [
  { name: 'パターンA', initialValues: { a: 30, b: 50, c: 60, d: 100 } },
  { name: 'パターンB', initialValues: { a: 25, b: 30, c: 55, d: 87 } },
  { name: 'パターンC', initialValues: { a: 10, b: 40, c: 70, d: 90 } },
];

// 各パターンごとに独立したフォームを作成
patternForms: FormGroup[] = [];

ngOnInit(): void {
  this.patternForms = this.patterns.map(pattern =>
    this.fb.group({
      a: [pattern.initialValues.a],
      b: [pattern.initialValues.b],
      c: [pattern.initialValues.c],
      d: [pattern.initialValues.d],
    })
  );
}

// HTML - パラメータを横並びで表示
<div class="parameters-grid">
  <div class="parameter-control">
    <h4>A</h4>
    <mat-slider>...</mat-slider>
  </div>
  <!-- B, C, D も同様に横並び -->
</div>

機能説明:

  • パターン選択: ラジオボタンで使用するパターンを選択できます
  • 選択パターンの値表示: 現在選択されているパターンの値がリアルタイムで表示されます
  • 3つのパターン常時表示: パターンA、B、Cが常に画面に表示されています
  • 横並びレイアウト: A, B, C, Dのパラメータが横並びで見やすく配置
  • 独立したフォーム: 各パターンは独立したFormGroupを持ち、互いに影響しません
  • スライダーと入力フィールド: それぞれのパラメータを視覚的・数値的に調整可能
  • プログレスバー: 各パラメータごとに異なる色で視覚化
  • 個別リセット: 各パターンごとに初期値にリセット可能
